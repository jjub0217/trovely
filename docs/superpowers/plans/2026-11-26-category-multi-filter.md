## 정한 것
- AND만(고른 카테고리를 모두 가진 게시물). OR는 하지 않는다.
- 기존 가로 버튼을 눌러 켜고 끈다. "전체" = 모두 해제, 마지막 해제 = 전체.
- "미분류"를 누르면 다른 선택이 풀리고, 다른 카테고리를 누르면 "미분류"가 풀린다.
- 주소: `?category=a&category=b`. 옛 `?category=a` 그대로 동작.
- 카테고리, 검색어, 출처 탭은 서로 유지. 키워드 검색과 비슷한 콘텐츠(벡터) 검색에 같은 조건.
- 결과 0개여도 조건을 풀지 않는다. 문구는 지금 그대로("조건에 맞는 콘텐츠가 없습니다").
- 버튼을 누를 때마다 기록을 남긴다(뒤로 가기 = 한 단계 전 선택).
- 선택 상한 10개(주소를 직접 고친 경우도 서버에서 정리).
- 기능 2(AI 공개) 코드는 만들지 않는다.
